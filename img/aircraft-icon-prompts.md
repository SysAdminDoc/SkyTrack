## Implementation Notes

1. **Generate at 256x256** then downscale to 64x64 for crisp edges
2. **Use SVG** if possible for infinite scaling
3. **Test visibility** on both dark and light map backgrounds
4. **Add white/black outline** (1-2px) for better contrast if needed
5. **Rotation**: Icons should face NORTH (up) - rotation will be applied in code based on aircraft heading

## Recommended AI Tools

- **Midjourney**: Use `--style raw` for cleaner icons
- **DALL-E 3**: Good for simple flat designs
- **Stable Diffusion**: Use ControlNet for consistent style
- **Adobe Firefly**: Good for transparent PNG export
- **Recraft AI**: Specifically designed for icons

## Post-Processing

After AI generation:
1. Remove background if not transparent (remove.bg or Photoshop)
2. Convert to single color if multi-colored
3. Center and crop to square
4. Export as PNG-24 with transparency
5. Optimize file size with TinyPNG
